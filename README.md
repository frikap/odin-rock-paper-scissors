# Rock Paper Scissors

A 5-round console-based Rock, Paper, Scissors game against the computer, built for [The Odin Project](https://www.theodinproject.com/lessons/foundations-rock-paper-scissors).

## Skills & Concepts Used

* **JavaScript:** Functions, scope, conditionals (`if/else`), `Math.random()`, case normalization (`toLowerCase()`).
* **HTML5:** Basic file structure and script integration.
