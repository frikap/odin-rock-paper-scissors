# Rock Paper Scissors

An interactive UI-based Rock, Paper, Scissors game against the computer where the first to reach 5 points wins. Built as part of [The Odin Project](https://www.theodinproject.com/lessons/foundations-rock-paper-scissors) curriculum.

## Features

* **Interactive UI:** Play directly via clickable buttons instead of console prompts.
* **Live Scoreboard & Feedback:** Real-time updates on round outcomes and current scores.
* **Game Over State:** Disables move buttons once someone reaches 5 points to prevent extra clicks.
* **Replay Capability:** Includes a reset button that resets scores and game state.

## Skills & Concepts Used

* **DOM Manipulation:** Selecting elements (`querySelector`), updating live content (`textContent`), and modifying element states (`disabled`, `hidden`).
* **Event Handling:** Attaching event listeners (`addEventListener`) and passing arguments using arrow functions.
* **JavaScript Logic:** Conditionals (`if/else`), template literals, random choice generation (`Math.random()`, `Math.floor()`).
* **HTML5:** Semantic structure, buttons, and non-blocking script loading (`defer`).
